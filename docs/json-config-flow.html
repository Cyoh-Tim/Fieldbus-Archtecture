비전문가가 손대는 곳

        
protocol, 연결 IP/포트, points[].name·주소·스케일. 프레임 포맷·PDU는 몰라도 됩니다.

      

      

        
코어가 하는 일

        
JSON 로드 → 어댑터 레지스트리 조회 → 사이클 타이머. 프로토콜별 지식이 없습니다.

      

      

        
어댑터·스택

        
주소 매핑, 엔디안, 스케일(eng = raw × scale + offset), 실제 패킷을 담당합니다.
