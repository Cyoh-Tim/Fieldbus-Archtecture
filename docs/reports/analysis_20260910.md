## 수정 내용 (High / 해당 Medium)

1. **H-001** — `cJSON_GetErrorPtr()`는 입력 버퍼를 가리킨다. `free(raw)` **이전**에 에러 포인터를 출력한다. `tests/test_fb_api.c`의 malformed reload가 회귀 경로.
2. **H-002** — Set.Res가 없으면 `finish_eth_step(..., 0, NULL, 0)` (다른 DCP 스텝과 동일). `flens[]` 제로 초기화.
3. **H-003** — `quantity>0`이고 `data==NULL`이면 `-EIO`. 길이 0이면 `memcpy`/`wire_words_to_be` 생략. `test_decode_empty_ok_payload` + qty 0 client read.
4. **M-001/M-002** — 비교를 `size_t`로 통일.
5. **M-003** — `strlen` ≥ dest이면 `-ENAMETOOLONG`, 아니면 `memcpy` (gcc truncation 경고도 해소).
6. **L-001** — 미사용 로컬 제거.

CI 플래그(`-Werror` 강제, sanitizer 끄기)는 변경하지 않았다. 기본 CMake는 기존과 같다. 로컬 분석만 `-Wall -Wextra -Werror` / `-fsanitize=`를 사용.

## 컴파일러 경고 노트

- **Clang 18** + `-Wall -Wextra -Werror`: 수정 전부터 통과 (sign-compare/format-truncation을 같은 강도로 안 냄).
- **GCC 13** + `-Werror`: 수정 전 4건 (`-Wsign-compare`×2, `-Wformat-truncation=`×2). 모두 이번 PR에서 제거.
- 프로젝트 CMake는 아직 `-Werror`를 켜지 않는다 (CI와 동일). 켜려면 GCC 13 기준 이번 수정이 선행 조건.
