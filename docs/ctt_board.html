CTT 테스트 보드

Controller Test Tool 시나리오 현황 — 무엇이 기본 CI에서 도는지, 무엇이 건너뜀·갭·범위 밖인지. CLI 엔진을 대체하지 않는 보드입니다.

NOT CERT
내부 CTT 보드 ≠ PI / ODVA 인증 증거. 내부 bundle-grade 게이트 ≠ PI 인증. 공식 PI Test Bundle, ODVA CT, Modbus.org, Mitsubishi 랩 리포트를 이 페이지의 통과 배지로 대체하지 마세요. PROFINET CC-C / IRT 는 제품 범위 밖입니다. 카탈로그: docs/ctt_pn_bundle.md (PN-B-*).

프로토콜 시나리오 제목 상태 CI / 라벨
조건에 맞는 항목이 없습니다.

통과

YAML 이 CMake add_test 로 등록되고 기본 mock CI ctest -LE soak_ci 에 포함됩니다.

건너뜀

opt-in. soak_ci, nightly soak, lab (CAP_NET_RAW) 처럼 PR 기본 게이트에서 빠집니다.

갭

매트릭스의 DUT-not-implemented / not yet. 예: MRP, Fast Start-Up, CIP TLS mock 미연결.

범위 밖

CC-C / IRT, 공식 PI·ODVA 랩, EtherCAT, RTU, SLMP ASCII/4E 등 영구 비목표.
